# Reflection
The biggest takeaway I got from this assignment was that each cafe's site needs a different scraping technique. For Lakeshore I used a class selector to find each heading, then the sibling slector to get the cards after it. For Hilltop, pd.read_html read the HTML tables and melt turned the S/M/L columns into one row per size. Canal Street was the hardest, the menues load with JavaScript so I had to select a shop, click buttons and use wait_for_selector. Without waiting, query_selector_all returns an emply list. For matching, normalization made similar names identical. That is why the thresholds only auto-match scores of 90 or more and send the rest to a human in the loop. For the gap analysis, an outer merge with indicator=True showed what only we sell, what only the rivals sell, and what we both sell. Where I need to improve for next time is finding ruff errors while I am writing the code. Some of my code cells were too long, had blank lines and were missing newlines. I also had an extra indent that caused an Indentation Error and broke every test until I was able to see the issue. I also believe that I need some more practice with Pandas axis=1 and with writing regex patterns.
